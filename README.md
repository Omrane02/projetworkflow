# Mémoire de France

Projet Git - YNOV SOPHIA B2 - 2026

---

## Description

Mémoire de France est un quiz qui permet de tester ses connaissances sur l'histoire de la France.

--- 
## Fonctionnalités
- Un quiz de type QCM à trois réponses
- Un choix de difficulté (facile, moyen, difficile)
- Un Choix de mode jeu (5, 10 ou 20 questions)
- Un système de score basé sur le pseudonyme
- Un scoreboard pour voir les meilleurs scores de la session

---
## Installation/Démarrage

Télécharger et lancer le fichier index.html
